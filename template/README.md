# 游目窗｜公开机器

这个目录可以独立部署。点地图 → RELEASE → 取信 → 翻面 → 下载 → 手动入藏。

**[部署、修改与收信规则](USAGE.md)** · [在线试玩](https://jianjidanbenren-eng.github.io/yomemado/template/)

- 名称、字体、音乐：`config.js`。
- 来信数据与图片：`letters.js`、`assets/stamps/`。
- 外壳配色：`custom.css`；保留交互元素 ID。

Vercel 根目录选本目录；Netlify 使用仓库配置。纯静态网页，无需后端或密钥。完整说明只维护在 `USAGE.md`；制票 Skill、来源、踩坑和可选后端接入都从那里进入。
