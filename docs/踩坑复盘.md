# 踩坑复盘

这份记录按「现象 → 原因 → 固定做法」写，避免把每个历史版本都搬进公开仓库。

| 现象 | 原因 | 固定做法 |
| --- | --- | --- |
| 邮票文字乱码、边框漂移 | 整张邮票交给生图模型 | 模型只做无字画芯，文字、齿孔与边框由程序套版 |
| 透明齿孔出现黑边 | 预览底色被写进图片，或两面用了不同蒙版 | 在 RGBA 导出后比对 Alpha，并在深浅背景上检查 |
| 网页看起来正确，下载图走样 | 屏幕与导出走了两条排版路径 | 同时验收网页与正反 PNG，统一字号与坐标来源 |
| 后台已经发布，网页没有新信 | 候选摘要或编号索引不是浏览器可读的完整来信 | 单独提供受限只读桥，发布后再做真实网页交互验收 |
| 最新来信未点入藏却提前入册 | 旧浏览器存储中的 `collected` 属于先前候选 | 手动收藏记录须绑定当前信内容；自动归档只看当前有效信 |
| 地名太长挤出机身 | 把事实全名直接塞入有限的印刷区域 | 事实全名与邮票短名分字段；不能删改事实来修布局 |
| 一次成功被当成永远成功 | 定时任务、生成、投递和网页各有独立失败点 | 每次记录来源、图片、哈希、索引、真实页面与通知结果 |

## 版本怎样保留

早期尝试用阶段性快照和关键决策保留，不把几十份过渡 HTML 与临时图片复制到公共仓库。私人档案可以保留原始证据；公开仓库只放能解释决定、能复用且授权明确的成果。
