## 公开视频的处理方式

- 来源：项目已有的 1920×1080 / 30fps / 45s 演示影片
- 网页版：1280×720 / H.264 MP4，约 2.3 MB，适配 GitHub Pages 和手机流量
- 封面：同一影片截出的 WebP
- **声音：不随公开版分发原视频音轨**；私人背景乐与第三方音效的授权条件独立处理
- **隐私：不接入私人 Site、插件写入接口、私信内容或任何凭据**

录制影像能说明设计效果，但不能代替源代码和自动化验收。公开视频为展示素材，不自动按仓库的 MIT 代码许可开放重用；参见 [公开边界](公开边界.md)。

## 与原网站的区别

公开视频记录了项目工作阶段的视觉与交互设计；GitHub Pages 页面是**公开项目手记**。它不获取私人收件索引，也不冒充完整可交互的 W51 原站。未来若发布真正可运行的公开模板，仍需单独制作替代音乐、授权字体和通用数据源。
