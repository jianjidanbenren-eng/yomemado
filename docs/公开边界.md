# 公开边界与素材

公开的是方法、原创说明和独立检查工具。项目的私人运行版与这个仓库分开。

| 内容 | 本仓库 |
| --- | --- |
| 设计过程、制票工序、踩坑与检查代码 | 包含 |
| 可一键部署的独立静态模板（`template/`） | 包含 |
| 45 秒静音项目演示和视频封面 | 包含；展示用途，不等同于可复用 UI 源码 |
| 原 W51 离线 HTML、W48 的 001 私用固定母版、原始来信和私人插件配置 | 不包含 |
| 音乐录音、付费音效、第三方字体文件及其 base64 内嵌数据 | 不包含 |
| 私人照片、完整生产 JSON、密钥和访问令牌 | 不包含 |

字体和背景音乐都不是制票方法的必要条件。若用第三方字体或音乐，请自行阅读作者授权并从官方渠道取得；不能把私用版里的内嵌内容直接复制到公开网站。原项目曾使用的「星光小熊猫体」请参见[作者仓库](https://github.com/cyberinkflow/StarPandaKidsFonts)及其[许可说明](https://github.com/cyberinkflow/StarPandaKidsFonts/blob/main/LICENSE)。本仓库不再分发该字体，也不暗示它采用本仓库的 MIT 许可。

## 演示视频与公开许可

`assets/yomemado-showcase-silent.mp4` 是从项目现有的 45 秒演示视频制作的**无声、1280×720 公开展示版**，保留了项目实拍/录屏的设计画面，不包含原视频的 AAC 音轨。`assets/showcase-poster.webp` 取自同一视频。

**授权边界：** `LICENSE`（MIT）适用于本仓库自行创作的代码与说明文字。演示视频和封面仅作为项目展示素材发布；除非权利人另行明确授权，它们不自动按 MIT 许可供他人重新发布、截取、商业使用或作为自己的模板。视频画面中出现的第三方内容仍由其各自权利人享有相应权利。

公开影片是观看原项目创作成果的入口，不是可重新部署的 W51 私人网页，也不代表公开了私人来信或站点 API。

这个页面也不提供访问私人站点的链接。现在仓库已提供 `template/` 独立静态模板：它使用虚构示例来信和公开重写的界面代码，可以单独部署，但仍不等同于私人 W51 完整源码。模板不带私人音乐、字体、来信、插件或密钥；若自行加入第三方素材，仍需分别确认授权。
