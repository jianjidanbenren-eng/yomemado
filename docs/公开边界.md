# 公开边界与素材

公开的是方法、原创说明和独立检查工具。项目的私人运行版与这个仓库分开。

| 内容 | 本仓库 |
| --- | --- |
| 设计过程、制票工序、踩坑与检查代码 | 包含 |
| 原 W51 离线 HTML、W48 的 001 私用固定母版、原始来信和私人插件配置 | 不包含 |
| 音乐录音、付费音效、第三方字体文件及其 base64 内嵌数据 | 不包含 |
| 私人照片、完整生产 JSON、密钥和访问令牌 | 不包含 |

字体和背景音乐都不是制票方法的必要条件。若用第三方字体或音乐，请自行阅读作者授权并从官方渠道取得；不能把私用版里的内嵌内容直接复制到公开网站。原项目曾使用的「星光小熊猫体」请参见[作者仓库](https://github.com/cyberinkflow/StarPandaKidsFonts)及其[许可说明](https://github.com/cyberinkflow/StarPandaKidsFonts/blob/main/LICENSE)。本仓库不再分发该字体，也不暗示它采用本仓库的 MIT 许可。

这个页面也不提供访问私人站点的链接。若将来发布独立可运行模板，需要先制作有明确权利的通用母版、示例图片和替代音效，并单独测试跨平台渲染。当前文档版不能声称已开放完整网站源码。
