# 公开版的内容与边界

公开仓库提供可部署的原机外壳、三枚历史测试样例、制票 Skill、三份提示词、共享母版、套版与检查程序、配置和部署说明。

默认公开示例为布达拉宫、普莫雍错、苏州留园。原六场景规范另含极地海面、开窗望海、长窗木桌；未找到对应的完整可追溯成品前，不宣称这次公开了六套。

私人来信数据、私人服务、凭据、独立背景歌曲文件、系统宋体和小熊猫字体文件不在模板中。项目演示视频按用户要求保留原片画面和现有音轨，视频及音轨不纳入代码 MIT 许可。公开机器直接读取随仓库提供的 letters.js 与 PNG，不向私人 API 或插件发请求。

机器外观可以修改；默认宋体可以更换；音乐地址可配置或关闭。修改已有 PNG 上的字需要重新导出，单改页面字体不会改变图片像素。

所有已入藏示例显示已读，旧信自动归档；最新一枚由使用者主动入藏。个人状态保存在各自浏览器。模板没有自动采风/生成/投递后端。

模板交付与演示视频分开：视频使用用户提供的 45 秒 1080p 有声原片，不裁切、不压缩、不去音轨；公开机器使用独立样例数据。原片记录 W41 阶段，其历史计数、字体、尺寸说明不替代当前模板规则。原片现有配乐与单独配置的背景音乐都需要按各自的公开使用权限处理，免费、署名或代码开源本身不等于歌曲授权。

原创代码与文档采用仓库 LICENSE；第三方来源见 ../THIRD_PARTY_NOTICES.md。


原版 W32 交互音效已保留，包括 V3 出票、翻纸、两段钢笔声和藏信开合；机音与背景音乐分别控制。音效更换与来源见 [使用说明](../template/USAGE.md)。
