# 公开版的内容与边界

公开仓库提供可部署的原机外壳、三枚历史测试样例、制票 Skill、三份提示词、共享母版、套版与检查程序、配置和部署说明。

默认公开示例为布达拉宫、普莫雍错、苏州留园。原六场景规范另含极地海面、开窗望海、长窗木桌；未找到对应的完整可追溯成品前，不宣称这次公开了六套。

私人来信、私人服务、凭据、原音轨、系统宋体和小熊猫字体文件不在发行内容中。公开机器直接读取随仓库提供的 letters.js 与 PNG，不向私人 API 或插件发请求。

机器外观可以修改；默认宋体可以更换；音乐地址可配置或关闭。修改已有 PNG 上的字需要重新导出，单改页面字体不会改变图片像素。

所有已入藏示例显示已读，旧信自动归档；最新一枚由使用者主动入藏。个人状态保存在各自浏览器。模板没有自动采风/生成/投递后端。

模板交付与演示视频分开：视频展示原作品，保持 45 秒静音剪辑；公开机器是真实可操作的独立数据版本。署名、原曲链接与音乐许可分别记录，歌曲文件没有因为免费开源而自动加入。
