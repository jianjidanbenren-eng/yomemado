# 公开介绍页的视觉基准

介绍页从原机的配色提取五种角色，延续旧邮政终端与浮世绘杂志的气质。它只是项目介绍，不复刻私人主机的交互。

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 氧化铁红 | `#7C2D12` | 章节签、邮政机器与强调 |
| 浮世靛蓝 | `#1B365D` | 标题、页眉和页脚 |
| 蓝晒海青 | `#4A777A` | 次级线条与层次 |
| 和纸米白 | `#F4EFEA` | 页面纸张底色 |
| 复古黄铜 | `#B89252` | 细线、旋钮与状态点缀 |
