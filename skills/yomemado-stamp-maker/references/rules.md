# 制票规则

## 规则适用范围

先区分沿用当前系列与明确设计新系列。本页的 736×1040、624×723、两行地名、固定字号和齿孔，是作者当前选定的默认版式。用户可按自己的想法更换形式、排版和大小；系列内保持一致，改版时按新规范重新验收。以下制作参数均默认指随包母版。

## 流程与比例

默认交付完整的正反面邮票，不停在画芯。两种入口由 Skill 自行完成“事实与短笺 → 无字画芯 → 固定套版 → 双面透明 PNG → 验收”；用户不需要再发下一条套版指令。照片模式保留原图主体；自主模式先核实事实与来源，再做原创氛围插画。画芯 624×723；整枚正反面 736×1040。

## 母版与文字

| 区域 | 处理 |
|---|---|
| 纸张、框线、齿孔、固定系列字样 | 使用 assets/master.png，所有样例复用 |
| 顶部地区与编号 | 从 regionShort 和 id 生成，固定居中基线 |
| 画内标题、副标题 | 从 pictureTitleShort、pictureSubtitle 生成，不让图像模型画字 |
| 底部地名 | footerShortLines 恰好两行，固定 49px 字级与基线 931/976 |
| 右下编号 | 与顶部 id 相同 |
| 地图、显示屏、藏信 | 使用地点全称，坐标未核实保留 null |

只在邮票印刷区使用准确简称。留园样例底部使用 LIU / YUAN，完整地点是 The Lingering Garden。不要将 LINGERING 缩字硬塞进固定宽度；程序会拒绝溢出。

## 透明与正反面

从同一母版复制 Alpha；纸张内部保留米白底，纸张外部与凹口透明。不要烘焙预览底色。检查实际 PNG，而不只检查 CSS 裁切。两面必须同尺寸、同 Alpha、四角透明、无黑边。直接下载网页中显示的同一对 PNG。

## 用户想换形式、排版或大小时

1. 从用户已给的需求确定外形、横竖比例、目标像素、画面与文字占比、字体和边缘处理；信息足够就执行，缺少决定成品的重要偏好时再问。方形、横版、不同字位或无齿孔均可作为新设计，不能将默认两行地名当成所有样式的规定。
2. 在用户自己的项目中另存新系列母版与版式记录，保留原默认系列。先用 TEST，不占正式编号；只有换了几何、排版或外形才走此步骤，普通换图、换短笺继续原套版。
3. 同步调整下列关联文件。新参数写进本次版式记录和生成数据；不编造现有脚本没有的命令参数。

| 关联部分 | 新版式需要同步处理什么 |
| --- | --- |
| `assets/master.png` 或用户的新母版 | 成品尺寸、纸张／外沿 Alpha、边框、固定字样和画芯区域 |
| `scripts/render_stamp.py` 的用户改版副本 | `SIZE`、画芯尺寸与位置、边角坐标、正反面字位、字号、宽度与基线；必要时适配数据字段 |
| `references/prompts.md` 的本次使用副本 | 画芯比例、构图留白和标题位置，保留主体；本包三份历史画芯原文继续留存 |
| `scripts/check_stamp.py` 的用户改版副本 | 目标尺寸、外沿／边角和 Alpha 条件；无镂空矩形不沿用四角必须透明的假设 |
| 可选机器接入 | 另行适配阅读区、出票缩略图、翻面容器和背面书写层的位置；实际存图与显示使用同一对成品 |

4. 用新规范实际导出一枚完整双面 TEST，检查尺寸、主体、字形、溢出、外沿与透明效果。默认尺寸检查器通过或不通过，都不能代替新设计的验收。
5. 同系列后续来信沿用这套新规范；新增样式不会自动改动机器、已发行邮票或声音。只请求生成邮票时，交付成品即可。

当前仓库仍提供已验证的默认渲染器，不宣称已实现通用任意版式引擎。更换形式是明确需求下的设计与适配流程；先把新母版定好，随后才稳定复用。

## 来源、样例与真实进度

保存来源、地名核对情况、画芯来源和生成方式。照片不等于图像版权已由上传者转让；不要擅自给第三方素材套 MIT。六套示例均保留原图、画芯、数据与完整双面成品。001–003 画芯是历史候选，不冒称本次重新生成；004–006 已从用户本次提供的原图新转绘并套版。原图字节与 SHA-256 保留，坐标和具体拍摄点未独立核实。

六场景的名称分开记录：布达拉宫、羊卓雍措（羊湖）、普莫雍错、里斯本・阿尔法玛窗与海、苏州留园、莫干山民宿山景长窗。羊卓雍措是蓝绿高山湖场景，普莫雍错是旧测试中的冰雪湖景；不能将两者互换。羊卓雍措、里斯本阿尔法玛、莫干山三项补充地名按用户 2026-10-28 的确认记录，具体民宿名称、窗景拍摄点和精确坐标仍不杜撰；随包六组完整示例已齐；机器仍只加载原有三封，不能把补齐 Skill 示例当成自动发行新来信。

失败时分别报告：画芯构图不符、文字溢出、缺少字体、透明失败或来源未核实。重新处理对应步骤，不把海报、整张带字 AI 邮票或旧图当成新结果。

原图与最终成品一并归档；对用户默认只展示完整正反面邮票，不发送画芯、草稿或过程预览。用户明确要求检查过程时再展示相应材料。
